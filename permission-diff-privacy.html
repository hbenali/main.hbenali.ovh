Permission Diff (Chrome and Firefox)

Privacy Policy

Last updated: November 2, 2026

Overview

Permission Diff is a browser extension that tells you when a website starts using a browser capability (such as geolocation or WebRTC) or loading a third-party domain that it did not use on your earlier visits.

The extension runs entirely in your browser. It does not send any data anywhere. It has no server, no account, no analytics, no telemetry and no remote code.

What is stored

For each website you visit, on your device only (in the browser's extension storage):

  • the site's hostname (for example example.com);
  • the hostnames of third-party domains the page requested resources from;
  • the names of browser capabilities the page used (for example geolocation, webrtc).

What is not stored

The extension does not store page content, URLs with paths or query strings, form data, cookies, passwords or your identity.

Why it needs its permissions

  • All sites: to observe capability use and requests on the pages you visit, so it can tell you what changed.
  • webRequest: to see which third-party hosts a page contacts. It only observes; it never blocks or modifies requests.
  • webNavigation and tabs: to know when a page visit starts and ends, and to show the result for the active tab.
  • storage: to keep the per-site baseline on your device.

Your control

The popup has a Clear stored data button that deletes everything the extension has stored. Removing the extension also deletes it.

Changes to this policy

If this policy changes, the "Last updated" date above will be revised.

Contact

Questions about this policy can be sent to contact@hbenali.ovh, or opened as an issue at github.com/hbenali/permission-diff.

Permission Diff (Chrome et Firefox)

Politique de confidentialité

Dernière mise à jour : 2 novembre 2026

Aperçu

Permission Diff est une extension de navigateur qui vous prévient lorsqu'un site commence à utiliser une capacité du navigateur (comme la géolocalisation ou WebRTC) ou à charger un domaine tiers qu'il n'utilisait pas lors de vos visites précédentes.

L'extension fonctionne entièrement dans votre navigateur. Elle n'envoie aucune donnée nulle part. Elle n'a ni serveur, ni compte, ni analytique, ni télémétrie, ni code distant.

Ce qui est stocké

Pour chaque site visité, uniquement sur votre appareil (dans le stockage d'extension du navigateur) :

  • le nom d'hôte du site (par exemple example.com) ;
  • les noms d'hôte des domaines tiers dont la page a demandé des ressources ;
  • les noms des capacités du navigateur utilisées par la page (par exemple geolocation, webrtc).

Ce qui n'est pas stocké

L'extension ne stocke ni le contenu des pages, ni les URL avec chemin ou paramètres, ni les données de formulaires, ni les cookies, ni les mots de passe, ni votre identité.

Pourquoi elle demande ses autorisations

  • Tous les sites : pour observer l'usage des capacités et les requêtes sur les pages que vous visitez, afin de vous dire ce qui a changé.
  • webRequest : pour voir quels hôtes tiers une page contacte. Elle observe uniquement ; elle ne bloque ni ne modifie jamais les requêtes.
  • webNavigation et tabs : pour savoir quand une visite commence et se termine, et afficher le résultat pour l'onglet actif.
  • storage : pour conserver la référence de chaque site sur votre appareil.

Votre contrôle

La fenêtre de l'extension a un bouton Clear stored data qui supprime tout ce que l'extension a stocké. Désinstaller l'extension supprime aussi ces données.

Modifications de cette politique

Si cette politique change, la date de « Dernière mise à jour » ci-dessus sera révisée.

Contact

Les questions sur cette politique peuvent être envoyées à contact@hbenali.ovh, ou ouvertes comme ticket sur github.com/hbenali/permission-diff.
