Install

What is Tessera?

Tessera is a fast, modern chat client for Matrix and Synapse that runs in the browser. This extension opens it in a drawer on the eXo workspace page. Open Tessera · Source code

Screenshots

Tessera itself, the chat the extension opens.

Firefox

Opens Tessera in a drawer on the eXo workspace page, with an unread badge on the chat icon. The add-on is signed by Mozilla and distributed here, not through the public add-on store.

Install for Firefox (0.1.0)

Firefox asks to allow this site to install add-ons, then shows the permissions. Accept both.

Chrome / Brave

Install it from the Chrome Web Store. This also works in Brave, Edge and other Chromium browsers, and updates automatically.

Add to Chrome (Chrome Web Store)

Check it works

  • Open community.exoplatform.com: the chat icon in the top bar is replaced by the Tessera icon.
  • Click it to open the drawer, then sign in to Tessera once.
  • Nothing happens? Open about:addons, the add-on, then Permissions, and allow access to community.exoplatform.com and tessera.hbenali.ovh.

Privacy

No data is collected. Read the privacy policy.

Qu'est-ce que Tessera ?

Tessera est un client de chat Matrix et Synapse rapide et moderne, qui fonctionne dans le navigateur. Cette extension l'ouvre dans un tiroir sur la page de l'espace de travail eXo. Ouvrir Tessera · Code source

Captures d'écran

Tessera lui-même, le chat que l'extension ouvre.

Firefox

Ouvre Tessera dans un tiroir sur la page de l'espace de travail eXo, avec un badge de messages non lus sur l'icône de chat. Le module est signé par Mozilla et distribué ici, pas par la boutique publique de modules.

Installer pour Firefox (0.1.0)

Firefox demande d'autoriser ce site à installer des modules, puis affiche les permissions. Acceptez les deux.

Chrome / Brave

Installez-la depuis le Chrome Web Store. Cela fonctionne aussi dans Brave, Edge et les autres navigateurs Chromium, et les mises à jour sont automatiques.

Ajouter à Chrome (Chrome Web Store)

Vérifier que ça marche

  • Ouvrez community.exoplatform.com : l'icône de chat de la barre du haut est remplacée par l'icône Tessera.
  • Cliquez dessus pour ouvrir le tiroir, puis connectez-vous une fois à Tessera.
  • Rien ne se passe ? Ouvrez about:addons, le module, puis Permissions, et autorisez community.exoplatform.com et tessera.hbenali.ovh.

Confidentialité

Aucune donnée n'est collectée. Lire la politique de confidentialité.
